# Abu Musa Rohan - Portfolio

> Frosted Glass CS Portfolio featuring high-performance vanilla HTML5, CSS design tokens, and printable resume.

## Overview
Personal engineering portfolio and CV showcase built with modern web standards, zero-bloat vanilla architecture, and dark-mode glassmorphic aesthetics.

## Highlights
- **Pure Semantic HTML5 & CSS3**: Zero heavy frameworks.
- **Design Token System**: Centralized typography, colors, and frosted glass variables.
- **Responsive Primitives**: Fluid layouts across mobile, tablet, and ultra-wide.
- **Native Print Engine**: Dedicated print stylesheet formatted for A4/Letter paper.
